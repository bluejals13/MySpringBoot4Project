### 한 가지 주의

 현재 테스트로 **직접 증명되는 것은 Repository 계층**입니다.

 따라서 아래 항목은 이번 15개 테스트만으로는 직접 검증했다고 쓰면 안 됩니다.

 - Publisher CRUD API
- Book CRUD API
- Publisher 삭제 제한
- DTO 변환
- Controller HTTP 응답
- Service의 비즈니스 로직
- `PATCH /books/{id}/detail`

 따라서 Verification 문서에서는 이렇게 표현하는 게 가장 정확합니다.

 > **Repository 계층에 정의된 Book/Publisher 조회, 검색, 존재 여부, 집계 및 연관관계 조회 계약에 대해 총 15개의 테스트가 모두 통과하였다.**

 그리고 현재 로그에서 실제로 Fetch Join도 확인됩니다.

```
book
left join book_detail
left join publisher
```

 그리고 Publisher → Book 조회에서도:

```
publisher
left join book
```

 이 실행되고 있으므로 **연관관계 조회 쿼리가 실제 Hibernate 환경에서 실행되었다는 근거**도 확보되어 있습니다.
