JPA Query Lab

① findById

Repository: studentRepository.findById(id)

특징: Student를 먼저 조회하고, LAZY 관계인 StudentDetail 접근 시 추가 SELECT가 발생할 수 있음

② JOIN FETCH

Repository: findByIdWithJoinFetch(id)

특징: Student와 StudentDetail을 INNER JOIN FETCH로 함께 조회

③ LEFT JOIN FETCH

Repository: findByIdWithLeftJoinFetch(id)

특징: StudentDetail이 없어도 Student를 조회할 수 있음
